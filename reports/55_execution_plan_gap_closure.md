## 阶段 1：抓放层 mode-specific 谓词（板书第三层，约 1 周）

**目标：把 pre-grasp / grasp / release / retreat 从"IK 插值"改进为 mode-specific IRIS 区域，并入统一 semantic GCS。** 这是 README 第 10 条欠账，也是 `valid_whole_body_interaction` 的落地。

**1.1 定义四个操作模式的构型空间区域**（2 天）
- pre-grasp：夹爪对准杯子上方、无碰撞的 10D 邻域（x,y,yaw + 7 关节）
- grasp：夹爪闭合、与杯子位姿对齐的窄区域
- release：杯子在箱体上方、倾倒/放置方向合法的区域
- retreat：放置后撤臂的走廊区域
- 方法：复用 `iris_region_generator.py` 的 10D 附着模式 IRIS-NP2 管线（携物门洞区域已验证 142ms/区域），把附着体从"杯子"换成各模式对应的状态
- 验收：每个模式至少 1 个 IRIS 区域通过独立抽样审计（ε=0.02, δ=0.05）

**1.2 接入 product graph**（2 天）
- 修改：`semantic_candidate_gcs.py` / `animate_delivery_demo.py`，让抓放阶段的转移经过 mode-specific 区域而非直接 IK 插值
- 保留 IK 作为回退路径（与 SE(2) 导航相同的回退模式）
- 验收：完整任务动画中抓放阶段轨迹段有对应的 GCS 区域标签（semantic trace 里可见）

**1.3 回归 + 演示更新**（1 天）
- 验收：旧 16 场景回归不回归；演示动画包含"进 grasp 区域 → release 区域"的可视化
- 风险：抓放区域窄（夹爪对齐容差小），IRIS 可能生成极小区域 → 需要调种子和 ε；若失败，诚实记录并分析原因
