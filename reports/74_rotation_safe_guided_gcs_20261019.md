# 旋转位移界、紧凑凸覆盖与非零朝向抓取复测

日期：2026-10-19。接续报告 73 的导航超时；物体布局、任务要求、目标底盘姿态保持不变。

## 修复内容

旧导航将 XY 无碰撞圆盘直接与 yaw 区间做笛卡尔积，未扣除机器人旋转造成的空间位移。修复采用固定收臂及固定夹爪模式下的刚体位移界，覆盖底盘、机械臂、夹爪的全部碰撞几何。

设任一机器人几何点到移动底盘旋转轴的水平距离不超过 R。对于构型变化 Δq：

```
点位移 ≤ ||Δxy||₂ + R |Δyaw|
       ≤ √2 ||diag(1,1,R) Δq||₂。
```

R 由碰撞几何位姿和包围形状上界计算，本场景为 0.4234679 m。种子构型的环境间隙为 d，所需余量 δ=0.0201 m。建立凸椭球：

```
||diag(1,1,R)(q−q_seed)||₂ ≤ (d−δ)/√2。
```

因此在固定机械臂/夹爪、静态障碍物和当前碰撞几何模型下，该区域具有基于位移上界的间隙下界。截断距离查询只能提供查询阈值的下界，代码显式截断返回值。再与导航域相交。该推导不覆盖机械臂同时运动、接触物体改变、动力学跟踪误差或未建模几何。

浮点距离与求解器容差仍需数值审计；不将其称为硬件安全或区间算术形式化证明。

## 规模控制与算法归属

使用官方 OMPL RRTConnect，在完整固定姿态机器人碰撞查询下寻找三维 `(x,y,yaw)` 引导。引导要求 3.01 cm 间隙，凸覆盖要求 2.01 cm，属于显式更保守的导航构造；不是证明原始 2.01 cm 问题不可行的判据。

只在现有椭球内部覆盖不足的引导位置添加新区域，并保留生成区域之间所有非空交集边。没有通过任意删边、图最短路或直线插值替代 GCS。最终轨迹仍由官方 Drake GcsTrajectoryOptimization、Clarabel、凸松弛与舍入求解。

这是 **OMPL 引导＋位移界凸区域＋官方 GCS** 的混合导航方法，导航区域不是 IRIS；机械臂操作保持原有官方 IRIS-NP2/GCS。引导覆盖缩小了搜索域，因此不保证覆盖全部同伦类别，也不声称与旧全覆盖问题具有相同全局最优值。
