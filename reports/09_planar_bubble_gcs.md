# 第一阶段：二维安全圆盘与语义 GCS

日期：2026-09-29。

检查仓库时，已有三维房间场景与 SE(2) 底盘多面体 GCS，但没有独立的二维圆盘实验。本轮新增该实验，没有替换现有机械臂仿真。

## 场景与建模

- 二维点机器人；大房间、小房间、1.3 m 宽门口、矩形障碍。
- 起点 `(-3, -1.5)`，取物点 `(2.4, -0.1)`，放置点 `(-2.5, 2)`。
- 固定网格及任务/门口种子自动生成 65 个圆盘；半径为种子到障碍物或边界的精确欧氏距离减去 0.06 m，并限制最大半径。小半径候选被省略，因此不宣称完整覆盖自由空间。
- 空手和携物各复制一层区域图，共 130 个区域节点，另加起点、取物和放置点节点。相交圆盘之间建边，并排除近乎相切的连接。
- 图的连接限定为 `start → empty → pickup → carrying → dropoff`，GCS 无法从空手层直接到终点。这里拾取、释放是固定位置的抽象动作，尚无杯子几何变化、抓取物理或泛化谓词编译。房间标签记录在语义轨迹中；到取物点必经小房间由该地图几何保证。
- 各区域内采用一阶 Bézier 线段，位置连续，未施加速度连续或加速度约束。动画按采样索引播放，不能解释为物理执行速度。
- 使用 Drake GCS + Clarabel，凸松弛后最多取整 10 条候选路径，不宣称全局最优。

## 本次运行

| 指标 | 结果 |
|---|---:|
| 几何圆盘数量 | 65 |
| 单层几何有向边 | 482 |
| 图构造时间 | 0.012 s |
| GCS 求解时间 | 3.029 s |
| 路径长度 | 11.207 m |
| 额外采样最小净空 | 0.07214 m |
| 先取后放及起终点检查 | 通过 |
| 逐段共同圆盘包含检查 | 通过 |

对每个圆盘，距离构造给出理想二维几何下的安全裕量。对每段输出线段，检查两个端点位于同一个安全圆盘，利用凸性获得整段包含性；计算仍采用浮点容差，并非形式化数值证明。另检查连接连续性和沿途采样净空。

额外检查了障碍内部与门中心的距离、全部圆盘裕量和三个任务点的图连通性。网页测试包含实际浏览器渲染、图层切换、播放以及终态检查。这些不构成多场景算法基准。
