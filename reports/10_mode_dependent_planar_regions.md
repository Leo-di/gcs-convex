# 状态改变碰撞几何：二维空手与携物实验

日期：2026-09-29。承接第 09 号报告；当前网页替换为本实验，旧的点机器人结果另存 `planar_point_baseline/`。

## 实现

场景有两条房间间通路：窄门宽 0.70 m，宽门宽 1.50 m。机器人采用二维圆形占据模型，空手半径 0.12 m，携物包络半径 0.42 m。这是为了验证模式相关几何而设置的负载尺寸，不代表原三维杯子的真实尺寸。

对相同地图与种子点，分别按模式生成中心位置的安全圆盘：

`区域半径 = min(0.95, 种子净空 - 模式实体半径 - 0.06)`。

过小区域被省略，不能据此宣称完整覆盖。圆盘内任何机器人中心位置加上对应实体圆形包络，均由距离的 Lipschitz 性保留规定裕量（理想几何模型下）。窄门中心允许空手通过，但携物直径 0.84 m 大于门宽，其不通行性不是人为删除指定路径实现的。

固定任务为 `start → pickup → dropoff`。取物点必须同时满足两种状态的安全性。由于取物位置固定、费用可加且没有跨阶段速度约束，本版本将两个模式的 GCS 分别求解并在取物点连接。这是固定语义顺序下的分解基线，**不是联合优化动作位置或任务次序的 product-graph 求解器**。

初次使用两层联合图的有限取整结果，空手也选择了宽门，尽管窄门覆盖可连通；不能把该结果解释成窄门不通或全局最优。最终固定动作点分解方案每次使用最多 20 条取整候选；仍不承诺最优性，也未进行公平求解器性能对比。

## 验证结果

| 指标 | 结果 |
|---|---:|
| 空手 / 携物圆盘 | 110 / 64 |
| 空手 / 携物有向连接 | 1440 / 512 |
| 两次 GCS 求解总时间 | 10.159 s |
| 总路径长度 | 12.103 m |
| 机器人外缘采样最小净空 | 0.09069 m |
| 空手穿越分隔墙的位置 | y = -0.1095 m，窄门 |
| 携物穿越分隔墙的位置 | y = 1.4589 m，宽门 |

求解输出检查：起终点、取物点连接、段间连续性、每段在对应模式的共同圆盘内、机器人外缘净空、实际过门位置。未指定两种模式必须经过的门作为优化约束；过门检查是求解后的验收条件。

新增 3 项测试全部通过：门中心对两种尺寸的可行性差别、区域与实体 Minkowski 和边界采样安全性、下方通道仅连接空手图。距离构造是整盘包含性的依据，边界采样只是实现检查。

浏览器检查通过：模式图层切换、自动跟随状态、取物时半径增大、完成放置后半径恢复、播放与终态显示。网页中的回放按采样索引推进，不代表动力学执行时间；轨迹分段位置连续，但未约束速度连续。
