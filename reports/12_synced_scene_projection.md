# 原三维执行记录的同步二维投影

日期：2026-09-29。

此前二维圆盘地图是独立算法实例，并非原三维场景的提取结果。本轮把主页面切回原任务数据，独立实验明确保留为对照。

## 唯一数据来源

`outputs/results/full_dynamics/validated/` 中的 `config.json`、`result.json`、`scene.html`。这是已有的 1 ms 接触动力学实验，持续 67.8 s，共保存 1,357 条实际状态记录。本轮没有重跑仿真或求解新轨迹。

- 三维页面复制原始 Meshcat HTML，内容逐字节保持；父页面控制播放器时间与初始观察距离。
- 二维墙体、家具尺寸、杯子尺寸与房间语义范围取自同一配置快照，不读取后来可能改变的配置文件。
- 底盘矩形按实际 x、y、yaw 变换；不是点机器人。
- 机械臂连杆原点和夹爪/手指位置，通过实际关节角和原机器人模型的正运动学计算。
- 杯子使用实际自由刚体姿态；将圆柱上下圆周变换后作 XY 投影凸包，48 点圆周离散用于可视化，不作碰撞证书。
- 接触力、参考阶段、杯子高度来自同一实际记录。阶段标注为参考调度，不冒充接触事件驱动的任务状态机。

## 同步与验证

共同滑块按实际记录索引选择仿真时间，三维动画调用同一时刻的 `animator.seek`。关闭独立三维动画控件，统一播放、暂停与速度。二维按记录采样显示，三维沿用原动画采样及插值；没有宣称两种采样逐位相同。

全部 1,357 帧的正运动学结果，都用原记录中独立保存的夹爪—杯子相对位姿作核对。最大矩阵元素/平移残差约 `5.329e-15`，阈值 `1e-8`。原始三个来源文件的 SHA-256 保存在投影 JSON，便于确认来源。

实际浏览器已检查加载、首帧/中段/末帧时间定位、播放暂停、阶段显示和主入口跳转。动画动作时间与请求时间一致（末端按动画片段长度截断）。

## 解读边界

机械臂橙色连线是各连杆坐标系原点的连接示意，**不是完整连杆碰撞包络**。家具画配置外包框，桌下空间没有被等同为不可通行；门框上横梁以虚线标出。俯视图重叠不能直接判为三维碰撞。

本页没有显示虚构的高维 GCS 区域圆盘。后续若增加规划区域展示，需要从实际规划记录提取，并明确使用切片还是投影；二维重叠也不能直接推出高维区域可切换。

## 使用

- 主入口：<http://127.0.0.1:7001/>，自动进入 `sync/`。
- 直接入口：<http://127.0.0.1:7001/sync/>。
- 原独立二维对照：`comparisons.html`，页面底部也有链接。

```bash
LCM_DEFAULT_URL=memq:// .venv/bin/python -m src.build_synced_scene
```

实现为 `src/build_synced_scene.py` 与 `src/synced_scene_view.html`。输出包括同步网页、原始执行与配置副本、原始三维 HTML、投影数据及来源校验值。
